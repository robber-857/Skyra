## 已实现

1. 既有基础：服务/Pass/周排期、Home/Programs 共享选课组件、Attempt/15 分钟 Hold、Shopify Cart、`orders/paid` HMAC 验签/去重/严格校验、Worker GRANT → RESERVE → Booking Confirmed、过期 Hold 安全恢复或 Needs Attention、已有 Pass 原子确认、付款/确认结果恢复。
2. Customer Account：独立 full-page 扩展；Upcoming / History / My Passes；25 条分页、Pass 余额/Reserved/Used/Expiry/Eligibility 和最近 20 条账本；每次请求获取 token，SDK 真验签 + 显式 audience/店铺/Customer/时效校验。不接受浏览器指定身份。
3. Class 生命周期：12 小时取消政策、Late Cancel、Admin 豁免、签到只记录到场、结束后出席/No-show 才 CONSUME、版本检查、幂等和不可修改的审计记录。
4. 原子改期：同 Class 类型、原课至少提前 12 小时、新课在窗口内且原 Pass 适用；排序锁住新旧 Session，在同事务中转移预留。满员/过期失败保留原预约。保留旧 Booking 的订单/Attempt 来源，创建新 Booking + BookingReschedule 关联；客户历史与后台可查。
5. Coach：未来 7/30 天和自定义日期人数、Roster、签到/出席/No-show。真实客户姓名/邮箱仍未接通，名册暂显示内部客户引用与预约编号。修复 Path=/coach cookie 导致 `/coach.data` 缺少会话的问题：新 cookie `skyra_coach_session_v2`，Path=/；旧会话需重新登录。
6. Admin：预约详情、状态操作、改期、课次流水、操作记录。Reports 支持近 7/30 天/自定义日期、预约状态汇总、已验证预约购买值和当前有效剩余课次；购买值不含其他全店订单和线下退款调整，不能当净收入。
7. 通知：确认和取消模板、Customer/Coach 幂等任务；取消/改期抑制未发旧确认。改期采用旧课取消 + 新课确认任务。provider 未接通，没有真实发信。
