## 502 的证据与边界

捕获 Node 请求 AggregateError：IPv4 250ms ETIMEDOUT，随后 IPv6 ENETUNREACH；2 秒连接竞速窗口仍不足。改为 IPv4 优先、关闭地址族竞速后，10 次独立连接均成功，但这不证明最终页面长期稳定；也观察到上游 503。

开发脚本只对子进程设置 NODE_OPTIONS 的 --dns-result-order=ipv4first --no-network-family-autoselection；诊断脚本设置同等 Node API。不修改系统 IPv6、TLS 或生产运行环境。参数依据：https://nodejs.org/api/cli.html#--no-network-family-autoselection 。用户反馈网络卡后已停止连续真实页面测试。
