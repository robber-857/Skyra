## 4. 最近两个故障及修复

### My account 的 localhost 401

原因：My account 原先是相对 `/account`，本地 Shopify 主题代理把认证请求导向 127.0.0.1。已改为 Shopify 托管账户 URL：保留 Liquid routes.account_url 的绝对 URL，相对路径使用 shop.permanent_domain 补全。

涉及：`booking-app/theme-extension-src/attempt.js`、`booking.js`、扩展 Liquid config、`shopify-theme/snippets/skyra-account-url.liquid` 和 7 个 Skyra section。

真实浏览器从本地 Home 已进入 `https://shopify.com` 的 “Sign in - Skyra Booking Dev”。未替用户提交邮箱或验证码；真实登录/退出/切换/返回未签收，不把登录页能打开当作登录成功。

### Admin Save draft 的 Bad Request

React Router 7.18.3 在单次数据 POST 进入业务 action 前校验 Origin。公网 HTTPS 经 Shopify CLI 转发为本机 HTTP，合法请求因此被误拒绝。

新增 `booking-app/react-router.config.ts`：allowedActionOrigins 只取 SHOPIFY_APP_URL（兼容 HOST）的精确 host。没有关闭 CSRF，没有允许所有 trycloudflare/shopify 域名。

测试通过真实 React Router request handler 调用 Schedule action，写入专用测试库的 DRAFT，重复提交保持一条；陌生 Origin 仍 400，可信 Origin 的未认证真实请求仍 401。用户本人 Save draft 是否最终成功尚未得到明确回报。

Render 部署需特别注意：allowedActionOrigins 是构建配置，必须确保构建时有正确的公开 App URL，或采用官方支持的运行时配置方式。不要把临时域名写死或以放开全部来源解决。
