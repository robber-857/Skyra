## 本批完成

1. 普通团课 `CLASS`、私教 `APPOINTMENT`、Workshop `COURSE` 已进入 Admin、Weekly Schedule 与公开 Booking flow；Pass 资格在应用层和数据库层都限制为单一课程类型。
2. Cart 失败诊断已改成安全结构化日志：记录操作类别、错误类别、HTTP 状态和 GraphQL code，不输出 access token、Cart secret、客户信息或完整响应体。
3. Customer Account Full-page Extension 已整理为六个入口：Overview、My passes、Bookings、History、Appointments、Profile。
4. Overview/My passes 显示次数余额、适用课程与到期时间；Bookings/History 显示预约状态、未来预约和历史记录；Appointments 单独显示私教预约状态并保留取消/改期操作。
5. Find a class 不复制排课 UI，使用扩展设置的 Storefront Programs URL，跳回 Home/Programs 共用的 Booking section。
6. Profile 新增可选头像、preferred name、签名和训练目标。Shopify 继续管理登录、正式姓名、邮箱、电话和地址。
7. Profile API 只接受已登录 Customer Account session token；文本有长度/控制字符校验，头像只接受 PNG/JPEG/WebP、校验真实文件头、上限 512 KiB，并只返回给同一店铺同一 Customer。
8. 新增迁移 `202609150013_customer_profile`，并把 Profile 页面同步到 [可点击线框](wireframes.html)。
9. 已实现仅开发店原生 Cart handoff：服务器创建 Hold/reference，浏览器使用已解锁密码页的同源 Shopify Cart，会在购物车非空或内容不完全匹配时停止，且不会自动清空。
10. 新增不可变 `handoffMode` 与迁移 `202609150014_native_cart_handoff`；旧 `UNKNOWN` Checkout 继续禁止重放，正式店服务器端 Cart API 保持不变。
11. `orders/paid` 对 `SKYRAUATFREE915` 增加严格开发店例外：只接受唯一指定 100% 折扣、折扣额等于商品原价且实付/小计为 0；其他店铺和折扣仍按金额不一致进入人工检查。
12. 通知入队时间统一改用数据库时钟，消除应用与数据库约 90ms 时钟差导致的即时领取竞争。
